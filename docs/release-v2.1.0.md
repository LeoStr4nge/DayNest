# DayNest 2.1.0 · 多语言与倒计时管理

Windows 11 x64 的 WinUI 3 桌面日历便携版。完整解压 `DayNest-2.1.0-WinUI-Portable-win-x64.zip`，运行 `DayNest/DayNest.Glass.exe`。包内包含 .NET、Windows App SDK 和 Python 后端，无需单独安装。

## 本版更新

- 新增简体中文、英语和日语界面。在“设置 → 外观与个性化 → 界面语言”选择并保存，重启后生效；旧设置默认保持简体中文。日语界面采用日语日期与星期写法，月历从周日开始。
- 视图切换的圆形指示器会随文字宽度伸展为两端圆角的长条；“设置”移到“+ 日程”同行，避免刷新按钮恢复文字后挤压布局。
- 新增“自动移除过期倒计时”，默认开启。日程当天仍显示，次日起自动取消桌面固定，不删除日历里的日程；关闭后可继续查看“已过 N 天”。
- 便携包只保留中、英、日三种 WinUI 控件语言资源，减少文件夹数量。

## 使用与兼容

需要 Windows 11 x64（build 22000 或更新）。更新前退出旧版并完整解压新包。账户与加密日程缓存继续保存在 `%APPDATA%\DayNest`；外观、语言和窗口位置继续保存在 `%LOCALAPPDATA%\DayNest`。默认使用桌面小组件模式；若找不到窗口，可运行 `DayNest.Glass.exe --normal-window` 恢复普通窗口。

本版仍是便携包，没有安装向导或代码签名。重复／全天日程编辑、跨日历移动等现有限制未变。源代码遵循 GPL-3.0-only，第三方许可证随包附带；可使用 `SHA256SUMS.txt` 核验压缩包。
