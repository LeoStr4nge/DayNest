# DayNest 2.0.0 · WinUI 玻璃日历

Windows 11 x64 桌面玻璃日历，采用 WinUI 3 界面并复用 Python CalDAV 后端。

## 下载与运行

下载 `DayNest-2.0.0-WinUI-Portable-win-x64.zip`，完整解压后运行 `DayNest/DayNest.Glass.exe`。包内附带 .NET、Windows App SDK 和 Python 后端，无需安装开发工具或单独配置 Python。保留所有文件和 `backend` 目录。

要求 Windows 11 x64（build 22000 或以上）。默认是桌面小组件模式，按 Win+D 查看；按住顶部三横线拖动，右侧 × 退出。若找不到窗口，运行 `DayNest.Glass.exe --normal-window` 唤回普通窗口。可在设置中填写账户、调整主题/玻璃，以及启用登录自动启动。

## 本版功能

- Acrylic 玻璃材质、六套主题、自定义强调色与可读性调整。
- 顶部固定三横线拖动区，移除原生顶部白条，保留边缘缩放。
- 今日、近期八天、本月日程；启动及十分钟自动同步、缓存恢复与相邻月份预加载。
- 单次日程新增/修改、图形化日期时间选择、完整备注和带确认的删除。
- 固定倒计时、备注预览与详情，跟踪其他设备的改期/删除及重复实例取消。
- 单实例、最小化恢复、跨目录唤回和登录自动启动。
- iCloud 与自定义 HTTPS CalDAV，DPAPI 保护账户密码和本地缓存。

## 兼容与数据

与原版共用 `%APPDATA%\DayNest` 的账户及缓存；使用前退出原版。外观/位置在 `%LOCALAPPDATA%\DayNest`。压缩包不含开发者账户、缓存或密钥。

重复/全天日程编辑、跨日历移动和重复系列整体改期后的固定实例对应仍沿用原版限制。此包是便携版，不包含安装向导；二进制未进行代码签名。启用自启动后若移动目录，请在新位置重新保存自启动设置。

完整源代码在此 Release 标签对应的仓库源码中，遵循 GPL-3.0-only；第三方许可证随包附带。可使用 `SHA256SUMS.txt` 核验下载文件。
