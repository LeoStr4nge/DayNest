# DayNest 2.1.1 · 严重缺陷修复

Windows 11 x64 的 WinUI 3 桌面日历便携版。完整解压 `DayNest-2.1.1-WinUI-Portable-win-x64.zip`，运行 `DayNest/DayNest.Glass.exe`。账户、加密缓存和外观设置沿用已有版本。

## 修复内容

- 修复设置页读取旧账户失败后，即使填写了完整的新账户和密码，也无法点击“保存并同步”的严重缺陷。现在可提交完整的新凭据；密码留空时仍不会覆盖无法读取的旧账户。
- 当 Windows 应用控制拦截日历后端组件时，设置页明确提示账户尚未保存，不再只提示检查 Python 环境。
- 中文、英文和日文 README 增加未签名便携版被“智能应用控制”拦截时的说明。

## 发布说明

本版重新构建 WinUI 前端；Python 后端与 2.1.0 发布包逐文件相同。发布环境中的 Python 运行时被 Windows 智能应用控制拦截，因此未重新冻结后端。包内继续包含 .NET、Windows App SDK 和 Python 后端，无需另行安装。

**仍未进行代码签名。** 若 Windows 智能应用控制拦截未签名程序，管理员身份也无法绕过；参见 [README](../README.md#安装与启动)。本版修复账户设置界面逻辑，不解决系统对整个便携包的拦截。关闭智能应用控制会影响整台设备的保护，请先确认来源和校验值，再自行决定。

更新前退出旧版并完整解压新包。可用随附的 `SHA256SUMS.txt` 核验压缩包。由于当前机器的系统拦截，未在真实账户上完成端到端同步验证。
