# DayNest · 日程小筑

把日程留在桌面，把重要的日子放在眼前。

DayNest 是一款 Windows 中文桌面日历小组件，支持 iCloud 预设和自定义 HTTPS CalDAV 服务，可自定义主题配色和窗口透明度。历史版本验证过 iCloud；本次多服务接入改造尚未经过真实服务器测试。

## 你可以用它做什么

- **随时查看安排**：返回桌面就能看到今天及未来七天的日程。
- **记住重要的日子**：将日程固定到顶部，显示“还有多少天”。
- **浏览日历**：切换月份，点击日期查看当天安排，有日程的日期会显示标记。
- **记录日程和备注**：添加或修改单次日程，填写标题、时间与多行备注。
- **阅读完整详情**：桌面显示一行备注预览，点击日程即可查看全文。
- **安排你的桌面**：拖动小组件到喜欢的位置，可设置登录 Windows 后自动启动。
- **搭配你的壁纸**：选择深色或浅色主题、自定义主题颜色，调整窗口透明度，让小组件融入桌面。

## 最近更新

- **多服务接入**：日历账户页可直接选择 iCloud，或选择自定义 CalDAV 并填写发现地址、可选的日历目录和跨域可信地址。切换服务时隔离缓存和后台结果，已有账户默认沿用 iCloud。

- **六套主题与自定义颜色**：新增午夜蓝、松林绿、暮光紫、暖玫瑰、云雾白、暖砂米；主题颜色可自由选择，也可恢复推荐配色。主组件、日历、详情窗口与滑块同步更新，文字颜色随配色调整以保持可读性。
- **设置页面重新整理**：分为“外观与个性化”和“日历账户”。“保存外观”可独立保存主题、透明度及桌面选项，无需填写账户；外观支持实时预览，关闭设置时恢复已保存的选择，保存后重启沿用。
- **透明度滑块美化**：采用细圆轨道、圆形滑块和百分比标签，配色随主题变化，并提供悬停和按下反馈，保留拖动及键盘调节。
- **日历文案通用化**：账户字段改为“账户名或邮箱”“日历密码”，按钮和同步提示统一使用“日历”或“日历服务”。iCloud 提供开箱即用的预设，其他 CalDAV 服务使用自定义连接配置。

## 安装与启动

需要 64 位 Windows 10 或 Windows 11。

**安装版（推荐）**：下载 Releases 中的 `DayNest-版本号-Setup-win-x64.exe`，双击按向导安装。无需安装 Python，可选择创建桌面快捷方式，开始菜单也会提供启动与恢复普通窗口入口。

**便携版**：下载 `DayNest-版本号-Portable-win-x64.zip`，完整解压后运行文件夹中的 `DayNest.exe`。请保留同一文件夹内的其他文件。

当前发布版本未进行代码签名，Windows 可能显示“未知发布者”或安全提示。请从本项目的 GitHub Releases 下载，并可使用随附的 `SHA256SUMS.txt` 核对文件完整性。

**从源码运行**：需要 Python 3.11 或以上版本。首次运行前，在项目文件夹中打开终端，执行：

```powershell
python -m pip install -r requirements.txt
```

之后双击 **DayNest.pyw** 即可启动，也可以运行：

```powershell
python DayNest.pyw
```

首次使用时，在 **设置 → 日历账户** 中选择 **日历服务**，填写 **账户名或邮箱** 和 **日历密码**，点击“保存并同步”。密码类型由日历服务决定，部分服务要求使用应用专用密码。

以目前已测试的 iCloud 为例：账户填写 Apple 账户邮箱，密码填写 **App 专用密码**，可在 [Apple 账户](https://account.apple.com/)的登录与安全设置中创建。

## 连接日历服务

**iCloud**：在“日历服务”下拉栏选择 **iCloud**，填写账户和 App 专用密码即可，无需手动填写 URL。旧配置会自动按 iCloud 处理。

**自定义 CalDAV**：选择 **自定义 CalDAV**，填写服务商提供的 HTTPS 地址及账户凭据。

| 字段 | 用途 |
| --- | --- |
| 发现地址 | 必填，可填写 `https://calendar.example/.well-known/caldav`、服务提供的用户地址或日历目录地址。 |
| 日历目录（可选） | 已知目录时可直接填写，跳过账户发现。 |
| 可信地址（可选） | 仅在服务跨域部署时填写，例如 `https://storage.example:8443`；多个地址用逗号分隔，不填写路径。 |

程序按发现响应查找日历，支持可信地址内的 HTTPS 重定向。服务返回的其他域名需要先加入可信地址，才会向其发送账户凭据。切换账户或连接配置时需要重新输入密码，并重新同步；旧服务的本地固定项、月份和资源缓存会被清除。每次连接一个服务账户。

当前支持 HTTPS 上的用户名/密码认证，不包含 OAuth 登录、HTTP 明文连接和订阅型 ICS 链接。**本次改造仅通过离线模拟协议检查，尚未经过真实服务器测试，包括 iCloud 预设回归和自定义服务。** 实际服务器的发现、同步及写入兼容性仍需验证。

## 使用方法

- 点击 **+ 日程** 添加安排；点击已有日程查看详情，再选择“编辑日程”修改。
- 点击 **日历** 浏览月份，在当天日程旁选择“固定到桌面”；点击固定项的 **×** 可取消固定。
- 点击 **刷新** 更新近期日程；在日历页点击“刷新本月”更新所查看的月份。
- 点击 **设置 → 外观与个性化**，选择午夜蓝、松林绿、暮光紫、暖玫瑰、云雾白或暖砂米主题。点击颜色按钮可自选主题颜色，“恢复默认色”会恢复当前主题的推荐配色。
- 拖动“窗口透明度”滑块可实时预览壁纸透出的效果（0%–60%），透明度仅影响主组件，文字也会一起变淡。
- 点击 **保存外观** 保存主题、颜色和桌面选项，无需填写账户；直接关闭设置会恢复原外观。账户信息位于 **日历账户** 页，修改后点击 **保存并同步**。

首次同步可能需要稍等片刻。再次打开时会先显示本地保存的日程，再自动更新。同一 Windows 登录会话只允许运行一个 DayNest 实例；重复启动会显示提示。

关闭主小组件即退出程序，不会常驻后台；关闭日历、详情或设置窗口只会关闭对应页面。如果正在保存日程，程序会等待保存结果后再退出。

## 常见问题

**找不到桌面窗口？**

先关闭已运行的 DayNest。安装版在开始菜单选择 **DayNest - 恢复普通窗口**；便携版可运行 `DayNest.exe --restore-window`；源码版双击 `RestoreWindow.pyw`。

**如何卸载？**

安装版可在 Windows 设置的“已安装的应用”中卸载。账户设置和日程数据默认保留，方便重新安装后继续使用。便携版关闭后删除解压文件夹即可。

**哪些日程可以编辑？**

目前可编辑单次、非全天日程。全天日程和重复日程请在对应的日历服务中修改；DayNest 暂未提供删除日程的功能。

**在其他设备上改期后，固定倒计时会自动跟随吗？**

会在启动、手动刷新或每十分钟自动同步时，更新原日历中固定日程的标题、时间和备注，改到未浏览的月份也能跟随。日程被删除或对应重复实例被取消后，会自动取消固定；读取失败时保留原固定项。跨日历移动或重复系列整体改期后无法对应到原实例时，请重新固定。

**支持其他日历服务吗？**

支持通过“自定义 CalDAV”接入提供 HTTPS 用户名/密码认证的日历服务，按上方说明填写连接地址。历史版本曾验证 iCloud，本次多服务改造尚未进行真实服务器测试；需要 OAuth 或专有 API 的服务尚未适配。

**本地数据放在哪里？**

账户设置和日程数据保存在 `%APPDATA%\DayNest`。不要公开分享这个文件夹中的文件。
