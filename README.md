# DayNest · 日程小筑

把日程留在桌面，把重要的日子放在眼前。

DayNest 是面向 Windows 11 x64 的中文桌面日历小组件。当前主界面使用 C# / WinUI 3，Python 后端负责 CalDAV 同步、日程解析和加密缓存。旧 Tk 界面及其安装包构建流程已退役，旧账户和缓存仍可沿用。

## 安装与启动

下载 [v2.0.1 WinUI 便携版](https://github.com/LeoStr4nge/DayNest/releases/tag/v2.0.1)，完整解压后双击 `DayNest.Glass.exe`。包内附带运行环境，无需另装 Python 或 .NET。需要 Windows 11 x64（build 22000 或更新），目前没有 WinUI 安装向导。

当前发布版本未进行代码签名。可使用发布页的 `SHA256SUMS.txt` 核对下载文件。历史版本的标签和压缩包继续保留。

首次使用在 **设置 → 日历账户** 中选择日历服务、填写账户和密码，再点击“保存并同步”。iCloud 需使用 [Apple 账户](https://account.apple.com/)生成的 App 专用密码。

## 使用方法

- **今日 / 近期 / 本月日程**：查看当天、未来七天或展开月历选择日期。
- **+ 日程**：选择目标日历，填写标题、起止日期时间和备注；日期和时间使用图形选择器。
- 点击日程查看完整详情，可修改单次非全天日程；删除前会提示确认。重复日程暂不支持编辑或删除，全天日程支持删除。
- 在详情中固定倒计时；点击固定项查看详情，右键取消固定。
- **设置 → 外观与个性化**：选择六套主题、自定义颜色、毛玻璃和浓度、桌面模式、过期倒计时自动移除及开机启动，点击“保存外观”保存。
- 桌面模式下按住顶部三横线拖动，按 Win+D 后仍可查看；右上角 × 退出程序。

启动先显示加密缓存，再同步日历；每十分钟自动同步。今日与近期视图只加载所需月份，打开月历后才预加载相邻月份，翻月优先复用缓存。手动点击“刷新”可立即更新。固定项会跟随其他设备上的改期或删除，网络失败时保留上次数据。

同一 Windows 登录会话只运行一个实例，重复启动会唤回已有窗口。保存日程期间关闭窗口，会等待写入结束再退出。

## 连接日历服务

**iCloud**：在“日历服务”下拉栏选择 **iCloud**，填写账户和 App 专用密码即可，无需手动填写 URL。旧配置会自动按 iCloud 处理。

**自定义 CalDAV**：选择 **自定义 CalDAV**，填写服务商提供的 HTTPS 地址及账户凭据。

| 字段 | 用途 |
| --- | --- |
| 发现地址 | 必填，可填写 `https://calendar.example/.well-known/caldav`、服务提供的用户地址或日历目录地址。 |
| 日历目录（可选） | 已知目录时可直接填写，跳过账户发现。 |
| 可信地址（可选） | 仅在服务跨域部署时填写，例如 `https://storage.example:8443`；多个地址用逗号分隔，不填写路径。 |

程序按发现响应查找日历，支持可信地址内的 HTTPS 重定向。服务返回的其他域名需要先加入可信地址，才会向其发送账户凭据。切换账户或连接配置时需要重新输入密码，并重新同步；旧服务的本地固定项、月份和资源缓存会被清除。每次连接一个服务账户。

当前支持 HTTPS 上的用户名/密码认证，不包含 OAuth 登录、HTTP 明文连接和订阅型 ICS 链接。**本次改造仅通过离线模拟协议检查，尚未经过真实服务器测试，包括 iCloud 预设回归和自定义服务。** 实际服务器的发现、同步及写入兼容性仍需验证。

## 常见问题

**找不到桌面窗口？**

在解压目录运行 `DayNest.Glass.exe --normal-window`，可唤回现有实例并切换为普通窗口。开发版也支持这个参数。

**从源码运行？**

参见[开发手册](docs/development.md)和 [WinUI 构建与功能说明](prototypes/DayNest.Glass/README.md)。运行编译后的 `DayNest.Glass.exe`；`daynest.py` 仅为后端模块。

**本地数据放在哪里？**

账户和日程保存在 `%APPDATA%\DayNest`，密码和缓存使用 Windows DPAPI 加密；外观与窗口位置在 `%LOCALAPPDATA%\DayNest`。不要公开分享这些数据。已有配置中的旧字段会保留，但不再由 Tk 界面读取。

**如何卸载？**

关闭后删除便携版目录即可。若启用了开机启动，先在外观设置中关闭并保存。个人设置和日程缓存默认保留。
