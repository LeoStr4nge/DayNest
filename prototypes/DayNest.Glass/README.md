# DayNest WinUI 玻璃日历

WinUI 玻璃日历现已合并到 main，作为 Windows 11 上的新界面。旧 Python/Tk 界面及其专用启动器、安装构建流程已退役；账户与缓存格式保持兼容。新界面用 C# 编写，CalDAV、DPAPI 账户读取及日程解析复用 Python。

## 构建与启动

需要 Windows 11、.NET 10 SDK、WinUI 构建工具，以及仓库 `.venv` 中已安装 `requirements.txt` 的 Python 环境。

```powershell
dotnet build prototypes/DayNest.Glass/DayNest.Glass.csproj -c Debug -p:Platform=x64 -p:OutputPath=bin/GlassFinal/
.\prototypes\DayNest.Glass\bin\GlassFinal\DayNest.Glass.exe
```

重新编译前先关闭该输出目录下运行的窗口。

发布便携包：在已安装 PyInstaller 的 Windows x64 Python 环境运行 `python tools/build_glass_release.py --version 2.0.1 --crt-dir <VS 的 x64/Microsoft.VC*.CRT 目录> --crt-license-dir <VS 的 Licenses/语言目录>`。脚本发布自带运行时的 .NET 前端并冻结 Python 后端，附带 VC++ 运行库，包不依赖源码目录。产物在 `release/`，附带 GPL 和第三方许可证、构建版本信息及 SHA-256 校验。发布说明见 `docs/release-v2.0.1.md`。

## 当前功能

- 自定义日期网格、翻月、今天、单日安排与完整备注。
- 先从原版加密缓存显示日程，启动后自动联网更新；每十分钟自动同步，可手动刷新所选月份。
- 翻月优先显示缓存，缺失或超过十分钟时自动加载；仅在月历展开时预加载相邻月份。今日视图只加载所需月份，近期视图只补齐八天范围涉及的月份。完整月份及资源缓存持久化到原版加密缓存，重启沿用。
- 添加单次日程，可选目标日历、起止日期时间与多行备注；新增后自动刷新对应日期。
- 日期下方显示日程标记，按跨天持续时间计算，午夜结束不标记下一天。
- 顶部显示固定倒计时；详情可添加，右键菜单可取消；点击固定项查看完整详情和备注。同步时按 UID 跟随其他设备的改期、删除及重复实例取消，保留网络失败时的原值。
- “近期”展示今天及未来七天，跨月自动补齐两个月的数据；跨天事件按每天归组、跨月缓存去重。
- 外观页提供原版六套主题、自选颜色与推荐色恢复、毛玻璃、桌面模式和登录 Windows 后自动启动。外观保存在 `%LOCALAPPDATA%\DayNest\glass-preview.json`，不改动原版账户配置。
- 切换月份会取消旧的读取进程；关闭窗口取消读取任务。

首次无账户时，请在“设置 → 日历账户”中配置。Python 内解密密码，不将凭据传给 WinUI 或进程命令行。读取/刷新不会修改账户；仅在账户页点击“保存并同步”时更新原版账户和必要的缓存隔离数据。

## 材质与稳定性

参考 [Pane 的 SceneB](https://github.com/LBEILC/Pane/blob/cfa1951069ea2656f582c7aee092783610c63e05/src/Pane.App/Hosting/SceneB.cs) 的染色/亮度分离与边缘高光设计，独立实现 `DesktopAcrylicController`。未复制 Pane 的双 HWND 宿主或 C++ 效果代码；双层阴影与饱和度效果尚未实现。

浓度范围 15%–80%，默认 42%。薄渐变染色保护文字对比度；系统根据透明效果、节能或失焦状态可能启用不透明回退。

自定义控制器持有独立的 `SystemBackdropConfiguration`，显式更新主题及激活状态，避免查询默认配置时 target 无效引起的 0x80070057 闪退。应用保留强引用。

## 两模块设置

主界面的“设置”打开“外观与个性化”和“日历账户”。外观页即时预览主题、颜色、毛玻璃开关和玻璃浓度；仅点击“保存外观”后持久化，取消或转到账户页保存不会保存外观及自动启动草稿。桌面模式的窗口框架变化在面板关闭后应用。

账户页支持 iCloud 预设与自定义 HTTPS CalDAV。密码通过重定向标准输入交给 Python，使用原版 DPAPI 加密保存；界面只读取 hasPassword 状态。留空保留旧密码，更换账户或服务必须重新输入。保存时使用后端互斥标识串行化读写，并保留已有配置中的其他字段。更换连接会清空原版旧账户的加密缓存与固定项，新界面同时清除内存列表，并同步所选月份；同步失败仍保留已保存的账户，可再次刷新。

账户改动真实写入 `%APPDATA%\DayNest\config.json`，请勿使用演示账户覆盖正在使用的账户。离线 check_bridge.py 使用模拟配置、加密和持久化，覆盖账号验证、密码保留/加密、账户切换缓存隔离及互斥写入保护。

## 折叠月历与日程操作

启动时月历折叠，显示当天安排；展开月历可选择其他日期，收起时回到今天。主界面备注只显示一行，超出宽度使用省略号；点击日程卡片查看完整备注。

详情面板默认只读，点击“修改日程”可编辑标题、起止时间和备注，保存使用原版 ICS 编辑逻辑及 If-Match。删除先显示确认警告，默认按钮是取消，确认后发送带 If-Match 的 DELETE。删除不重试、不跟随重定向；服务器版本冲突或权限错误会保留原数据并提示。重复系列与例外实例暂不开放编辑或删除，避免误删整组；全天日程允许删除，编辑仍需使用原日历服务；缺少资源地址或 ETag 时需先刷新。

操作令牌使用 DPAPI 加密并绑定账户与连接，原始 ICS 不传给 WinUI，账户改变后旧令牌失效。成功写入后更新/移除原版固定项缓存、失效月份和资源缓存，再刷新界面。后端互斥量阻止并发写入，也兼容尚在运行的历史版本。写入过程中关闭主窗口会等待操作结束。

离线验证：

```powershell
.\.venv\Scripts\python.exe -B tests/check_delete.py
.\.venv\Scripts\python.exe -B prototypes/DayNest.Glass/check_event_actions.py
```

以上检查使用模拟服务器，覆盖确认参数、版本冲突、账户绑定、重复日程保护、固定项更新及缓存失效。界面验证仅打开真实日程、进入编辑及取消删除，没有向真实服务写入或删除测试日程。


## 今日、本月日程与固定项

默认“今日”隐藏月历并显示当天所有安排。“本月日程”返回当前月份，展开月历并显示整月列表，跨月持续事件也纳入；点选日期后查看当天安排。翻月切换到该月列表；点击“今日”返回今天。

日程详情上方可“固定到桌面”，已有固定项会显示“已固定到桌面”。编辑草稿时该按钮禁用，先保存修改后再固定。重复日程、全天日程也可固定，不受服务器写入限制。倒计时右键菜单（键盘也可用菜单键）提供“取消固定”，只移除固定项，不删除服务端日程。

固定项操作通过绑定账户与操作用途的 DPAPI 令牌完成，不调用 CalDAV。添加去重，取消时只移除所选固定项；所有内存月份同步更新，重启后从加密缓存恢复。后台读写通过互斥量协调；过期固定项显示“已过 N 天”，仍可取消。

固定项按时间排序，备注仅显示一行省略预览，点击可打开完整详情；缺少服务器元数据的旧固定项也能只读查看。倒计时跨日自动更新；相同内容不会每分钟重建卡片，避免打断右键菜单。

启动、手动和十分钟自动同步会复用原版 `pinned_resources()` / `tracked_pin_event()` 按日历地址和 UID 发起不带时间范围的查询，支持改到其他月份、资源地址变化、重复实例改期/取消，以及从旧缓存恢复实例标识。同一 UID 只查询一次。确认删除或取消才移除固定项，网络、权限或解析失败保留原值并提示。后台相邻月份预加载不重复查询固定项；最新固定项会更新所有内存月份，避免切换页面恢复旧倒计时。固定项变更与月份缓存共用原子加密写入。

验证：`.\.venv\Scripts\python.exe -B prototypes/DayNest.Glass/check_pins.py`。测试使用模拟加密和缓存，覆盖重启读取、去重、旧格式取消、重复日程固定、账户隔离和不触碰服务器。

跟踪验证：`.\.venv\Scripts\python.exe -B prototypes/DayNest.Glass/check_pin_tracking.py`，使用模拟服务器覆盖跨月移动、备注/详情、确认删除、重复实例、旧固定项恢复、查询去重、失败保留和预加载排除。

## 六套主题与登录自动启动

主题沿用原版午夜蓝、松林绿、暮光紫、暖玫瑰、云雾白、暖砂米。可用图形化颜色选择器设置强调色，或恢复当前主题推荐色。主界面、月历、固定项、系统按钮及弹窗共享配色；选中日期的文字自动选择黑/白，强调文字向正文颜色调整，以保持可读性。玻璃材质独立保留，不用整体降低文字透明度。

自动启动在点击“保存外观”后更新当前用户 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 的 `DayNest` 值，命令为加引号的当前 WinUI EXE 路径及 `--autostart`。沿用原版键名，避免同时启动两套界面；取消设置不改注册表。旧外观配置未记录此项时只读取现有启动状态，明确保存后才迁移入口。已保存开启时，正常启动可刷新 EXE 所在路径。诊断模式不执行路径迁移。

保存将启动项与外观一起处理：启动项写入失败保留旧外观；外观文件保存失败则恢复原启动命令并提示错误。原版账户设置保持独立。开发版仍依赖当前仓库、Python 环境及 .NET 运行环境，目录删除后对应启动命令也需更新。

`--self-test` 在临时配置与模拟启动项中检查六套主题及极端颜色对比度、旧配置兼容、保存/恢复、自启动命令引号、启用/禁用及跨资源回滚，不修改真实注册表。失败会写入 `self-test.txt` 并返回非零退出码。

## 图形化日期与时间输入

日程详情默认以只读文本展示开始/结束时间，进入“修改日程”后显示日期按钮和时分按钮。点击日期弹出可翻月、选年/月的系统月历；点击时间弹出 24 小时制的小时/分钟选择器，按勾选按钮确认时间，按叉或取消关闭弹窗。仍需点击详情的“保存修改”才会提交日历服务，取消详情会丢弃日期和时间草稿。

调整开始日期或时间时，结束时间会同步顺延以保留当前时长；可单独修改结束日期或时间调整时长。保存仍校验结束晚于开始，以及系统时区内的无效时间。查看状态不显示可编辑选择器。已实际验证日期弹窗、开始日期变化时结束日期顺延、时分弹窗和取消草稿，未修改真实日程。

## 桌面小组件模式

默认启用，可在“设置 → 外观与个性化 → 桌面小组件模式”中切换，点击“保存外观”记住选择，取消恢复原模式。桌面模式隐藏系统标题栏、任务栏和 Alt+Tab 项目；按住顶部固定的三横线区域拖动，右侧 × 退出。拖动区不随日程滚动，标题文字不再承担拖动操作。位置单独保存在 `%LOCALAPPDATA%\DayNest\widget-position.json`，重启恢复；显示器布局变化时限制在最近显示器的工作区内。

桌面模式通过 `WM_NCCALCSIZE` 将客户区扩展到整个窗口，去除隐藏标题栏后残留的浅色顶部边条，同时保留原生缩放样式并处理边缘命中。普通窗口模式恢复系统框架。顶部拖动区与内容共用玻璃和渐变底色，关闭按钮位于拖动区之外。桌面检查覆盖顶部原生留白为零、三横线的拖动分区、关闭按钮排除及顶部/侧边缩放命中。

窗口保持为 WinUI 顶层窗口，不嵌入 Explorer，保留 Acrylic 材质。通过工具窗口样式与 250 ms 的 UI 线程检查处理桌面层级：桌面激活时显示，其他应用激活时降到后面，不抢焦点；Win+D 显示桌面后仍可见。桌面模式保持玻璃材质的激活外观，避免点击桌面后变成不透明背景。

运行以下命令可启动或唤回普通窗口：

```powershell
.\prototypes\DayNest.Glass\bin\GlassFinal\DayNest.Glass.exe --normal-window
```

已有 WinUI 实例时，直接携带 `--normal-window` 再次启动即可唤回现有窗口并恢复普通窗口，无需先退出。该参数不自动保存外观设置，普通窗口可在任务栏和 Alt+Tab 中找到。设置或详情打开期间，等该面板关闭后切换窗口框架。

开发检查：`DayNest.Glass.exe --desktop-check` 强制启用桌面模式，通过 Shell 的 Show Desktop 接口连续切换三轮，检查窗口未最小化、未隐藏且未被 DWM cloak；同时检查普通窗口恢复和重新启用。结果写入 `desktop-check.txt`，结束后关闭测试窗口并恢复 Shell 切换状态，不保存外观或窗口位置。`--self-test` 另覆盖模式保存、负坐标位置保存和损坏配置恢复。

## 新增日程、自动同步与月份缓存

“+ 日程”打开新增表单，可选择账户下的目标日历，填写标题、图形化的起止日期/时间和多行备注。开始时间变化时保留时长，保存前校验标题与结束时间。当前新增单次、非全天日程，与原版新增能力一致。取消不会向服务器写入；成功后切到所选日期并刷新。每个表单使用固定 UUID 和 `If-None-Match: *` 条件创建，避免响应丢失后重试产生第二条日程。日历选择令牌由 DPAPI 加密并绑定账户、连接和操作用途。写入过程中延迟退出，不自动重试写入；服务器已成功但缓存更新失败时明确提示，避免误以为添加失败。

启动先显示缓存，再强制联网同步可见月份。每十分钟自动刷新，设置/详情/写入期间跳过自动同步，关闭页面后恢复加载；每分钟检查日期变化和倒计时，今日视图跨午夜自动切换日期。翻月及点选日期复用十分钟内的完整月份缓存，缺失或过期时自动读取服务器。今日视图不预加载相邻月份，近期视图只加载今天及未来七天涉及的月份；只有月历展开时才预加载前后各一个月，不额外加载无关的当前自然月。收起月历或切换视图会取消旧预加载。同步接口仍按整月读取，今日视图并非单日查询。未完整读取的月份与“已同步但没有日程”分别提示。

日程数据更新时建立月份日期索引，日期标记和单日列表直接查索引；近期视图使用覆盖八天的合并索引，并对跨月日程去重。开始日包含在内，结束时间恰好为午夜时不计入下一天；跨天、全天和零时长日程保持原显示规则。只更新固定项、状态或主题不会重建索引，月份被淘汰或账户/日程缓存清空时释放相应索引。隐藏的月历不再构建日期控件。

完整同步结果复用 `%APPDATA%\DayNest\cache.dat` 的 DPAPI 加密和原子替换格式，保存月份、正文/ETag 及日历发现结果，保留固定项。持久月份仍限制为当前月前后各六个月，远月仅暂存在内存。多个日历全部读取成功才替换缓存；离线或部分失败保留原缓存及界面。磁盘保存失败仍展示已同步数据并提示。日历发现结果复用 24 小时，资源正文沿用原版增量读取逻辑。

WinUI 的读取、预加载和写入共用进程请求队列，写入前取消并等待旧读取进程退出。网络刷新持有原版命名互斥量，防止账户切换、固定项或其他桥接进程并发覆盖缓存；仍兼容历史版本的锁。WinUI 启动单实例使用独立锁，避免其 Python 桥接进程被应用自身的实例锁阻止。

## WinUI 单实例与重复启动

正常启动在读取账户、外观和缓存之前申请独立的 Windows 命名互斥对象。同一 Windows 用户、登录会话内仅一个 WinUI 实例，不以 EXE 路径区分，跨构建目录同样生效。锁保持到 WinUI 主循环退出；正常关闭和进程异常结束后由 Windows 释放。`--self-test` 只操作临时文件，不启动界面，不占用应用实例锁。

重复启动通过仅限当前用户访问的命名管道通知已有实例后退出，不再弹出第二个日历或阻塞式提示。现有实例会恢复最小化窗口并请求前台显示，保留当前日期、设置、详情和未保存草稿。启动阶段的通知会暂存，等窗口构建完成后处理。创建锁失败时停止启动，通知失败时仅在旧进程已退出且成功获得锁后启动新实例。

`--normal-window` 可从重复启动请求现有实例恢复普通窗口，不自动写入外观设置。若面板仍在编辑，先保持弹窗宿主不变，在关闭面板后应用标题栏和窗口层级变化；取消设置会保留这次明确请求的普通窗口模式，其余未保存外观仍按原逻辑恢复。前台显示仍受 Windows 焦点规则约束。
